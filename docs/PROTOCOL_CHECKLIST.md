# 固件与协议对接资料清单

每个系列/型号建立一份能力记录，先只读，再逐项评估控制能力。不要套用其他品牌或型号的寄存器表。

## 基础资料

- 产品系列、型号、硬件版本、固件版本及适用范围。
- 设备拓扑：逆变器、通信模块、电表、BMS、并机组的关系。
- 设备唯一 ID 的来源、生命周期及与 mDNS TXT 的对应关系。
- `_energylib._tcp.local.` 实际服务记录样例及抓包的脱敏说明。
- 本地业务协议、TCP 端口、加密、认证、配对、凭据撤销和证书验证方式。
- 离线是否可用、云账号是否必要、最大连接数和限流要求。

## 读取接口/点表

建议覆盖：设备身份、运行状态、光伏各路及合计功率、电网进出功率、家庭负载功率、电池功率与 SOC/SOH、温度和告警，以及累计发电/购电/上网/电池充放电电量。

每个字段都应提供：

| 字段信息 | 要求 |
| --- | --- |
| 地址或接口 | 寄存器/方法/路径/主题，依据实际协议确定 |
| 类型 | 数据长度、字节序、字序、有无符号 |
| 单位和缩放 | W/kW、Wh/kWh、百分比、倍率及精度 |
| 方向 | 电网购电/上网、电池充电/放电的符号含义 |
| 有效性 | 空值、无效标记、过期、故障、未安装部件时的含义 |
| 刷新 | 更新时间、建议轮询周期、是否支持推送 |
| 统计 | 累计值清零/溢出规则、时区、日统计边界 |
| 能力范围 | 哪些型号、固件及单机/并机拓扑支持 |

## 控制接口

逐项确认工作模式、手动充放电功率、SOC 上下限/备用电量、时间计划、馈网限制和关联负载控制是否提供。每项需说明：

- 允许值、单位、额定能力限制及生效条件。
- 读写权限、是否需要额外授权、是否永久保存。
- 命令成功/拒绝/超时的返回形式和错误码。
- 如何从设备回读实际状态；生效延时、人工覆盖和冲突处理。
- 断线、控制服务退出或调度过期时的设备行为。

未明确的控制字段不得进入实现，也不得通过猜测寄存器或扫描写地址来试验。

## 开发资料与实机

- 经授权可使用的协议说明；确认是否允许在仓库中分发。
- 脱敏的请求/返回样例、状态变化样例和异常数据。
- 只读联调用的设备或协议模拟器；记录测试型号与固件。
- 控制测试前确认人员、时间窗口、设备状态、授权范围和恢复方案。

## HA 能源统计

优先使用设备自身的有效累计电量计数器，按其语义选择 energy 设备类型、kWh 等单位及合适的统计状态类型。瞬时功率与累计电量应分开；没有直接累计计数时，再评估由功率积分的精度和限制。设备数据未知或接口失败时，应表示不可用，不发布零值来掩盖问题。
