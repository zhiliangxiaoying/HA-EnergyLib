# EnergyLIB Home Assistant 用户操作说明

适用版本：`0.8.38.dev1`。更新日期：2026 年 10 月 23 日。

本说明面向日常使用者和负责首次配置的管理员。日常查看建议使用 **EnergyLIB → 总览**，查看家庭能量流动可进入 **数字孪生**；安装、设备添加和权限配置由管理员完成。

当前为开发预览版，支持通过采集棒连接的盛弘 V001B031 单机协议设备，不支持并机。已完成一台三相 12 kW 实机的读取及部分参数写入回读验证，**电池强制充放电尚未完成实机验证**。实际可用项目以连接设备识别出的能力为准。

## 1. 已安装用户：从这里开始

| 想做什么 | 去哪里 | 怎么操作 |
|---|---|---|
| 看光伏、电池、电网和家庭用电 | EnergyLIB → 总览 | 查看功率、今日电量和电池电量 |
| 看 3D 能量流动 | EnergyLIB → 数字孪生 | 打开后等待场景和数据加载 |
| 看具体故障 | 总览 → 设备告警 | 查看异常名称，展开来源、代码和最近记录 |
| 看长期用能 | 左侧“能源” | 首次由管理员选择累计电量传感器 |
| 改 EMS 模式或 SOC | 总览 → 运行控制 | 管理员先开放控制权限并启用相应实体 |
| 设置每天重复的充放电 | 集成配置 → 定时充放电 | 编辑时段、预览并保存 |
| 临时让电池充电或放电 | 总览 → 电池强制充放电 | 开启远程权限、填功率与时长，再点击开始 |

只查看数据时，不需要开启任何控制权限。

## 2. 首次安装与添加设备

### 2.1 安装前准备

需要 Home Assistant 2026.8.2 或更新版本，以及能够通过局域网访问的采集棒 Modbus TCP 服务。准备好采集棒的 IP 地址、业务端口和 Modbus 设备地址。

自动发现还需要 HA 与采集棒之间允许 mDNS 多播；发现不了时仍可尝试手动添加。不同 VLAN、访客网络或无线客户端隔离可能影响发现和连接。

### 2.2 安装集成

通过 HACS 自定义仓库安装：

1. 打开 **HACS → 右上角菜单 → 自定义存储库**。
2. 填写仓库地址 `https://github.com/zhiliangxiaoying/HA-EnergyLib`，类别选择 **Integration（集成）**。
3. 下载 EnergyLIB，随后重启 Home Assistant。

也可手动将仓库内的 `custom_components/energylib` 文件夹复制到 HA 配置目录的 `custom_components/` 下，再重启 HA。

### 2.3 自动发现添加

1. 进入 **设置 → 设备与服务**。
2. 找到“已发现”中的 **EnergyLIB**，点击 **添加**。
3. 核对采集棒 SN、型号、固件版本及连接参数。
4. 点击提交，等待读取逆变器身份并完成添加。

发现页中的 SN 和固件来自采集棒广播；连接后另外读取逆变器 SN，两者可以不同。采集棒信息不能代替逆变器身份核对。

自动发现的端口来自设备广播的服务记录，不一定是 502；端口不需要出现在 TXT 属性列表中。请保留设备实际广播的端口，除非已确认它需要修改。

### 2.4 手动添加

进入 **设置 → 设备与服务 → 添加集成 → EnergyLIB**，填写：

| 字段 | 填写内容 |
|---|---|
| IP 地址或主机名 | 采集棒在局域网中的地址 |
| Modbus TCP 端口 | 手动添加默认 502，必须与设备实际端口一致 |
| Modbus 设备地址 | 默认 1，可填写 1～255 的整数；以设备配置为准 |

提交失败时先检查这三项及网络连通性。能发现设备只说明收到了广播，不代表 Modbus 服务一定可以读取。

## 3. 打开 EnergyLIB 页面

如果左侧还没有 EnergyLIB 页面，进入 **设置 → 仪表盘 → 添加仪表盘 → EnergyLIB**，创建后打开。

### 3.1 总览

桌面宽屏下，总览主要分为三列；窄屏和手机会依次排列。

| 区域 | 主要内容 |
|---|---|
| 左列 | 能量流、实时功率、今日电量、累计电量、运行记录 |
| 中列 | 电池电量及趋势、近 7 天每日电量、功率趋势 |
| 右列 | 运行状态、设备告警、运行控制、定时充放电、电池强制充放电 |

“电池强制充放电”放在控制区靠后的位置。没有开放控制时，页面仍可查看测量数据。

安装可选的 **Power Flow Card Plus** 前端卡片后，总览会显示能量流图；未安装时仍显示功率卡片。数字孪生不依赖这张卡片。安装方法见 [项目说明](../README.zh-Hans.md#energylib-页面)。

### 3.2 数字孪生

点击 **数字孪生** 标签页，查看 3D 房屋、光伏、电池、电网和家庭负载的能量流动。有多台设备时，先确认当前选中的设备。

场景会先显示主要内容，汽车模型随后加载。首次加载或清理浏览器缓存后可能比后续打开耗时更长。动画表示当前功率方向，不能代替累计电量统计。

若显示“数据不完整”，SVG 和 3D 能流会暂停，灰线仅表示接线示意；有效功率数据恢复后，动画自动继续。家庭不会向外供电，负载读数为负时按 0 W 显示：30 W 以内视为计量误差、不提示；更大的负值会在顶部用一行文字注明实际读数。

管理员若希望在左侧“概览”或其他仪表盘中单独展示数字孪生，可使用以下视图配置。它与 EnergyLIB 页签使用同一资源版本，升级后刷新页面即可加载新版，无需手动修改 iframe 后的版本号。

```yaml
views:
  - title: EnergyLIB 数字孪生
    path: digital-twin
    strategy:
      type: custom:energylib-twin
```

将视图加入已有仪表盘时，保留其他视图，只添加或替换对应的一项。已有旧版 iframe 卡片的页面不会由插件自动改写，需要管理员执行一次转换。

## 4. 看懂功率、电量和更新频率

### 4.1 功率与电量

**kW 表示当前功率，kWh 表示一段时间内的电量。** 例如，持续以 2 kW 运行半小时，理想情况下对应 1 kWh 电量；实际结果还会受到功率变化及损耗影响。

| 项目 | 怎么理解 |
|---|---|
| 光伏总功率 | 当前光伏发电功率 |
| 家庭负载功率 | 当前设备上报的家庭负载功率 |
| 电池功率为正数 | 电池正在放电 |
| 电池功率为负数 | 电池正在充电 |
| 电网功率为正数 | 正在从电网购电 |
| 电网功率为负数 | 正在向电网上网、卖电 |
| 电池总电量（SOC） | 电池剩余电量百分比，不是 kWh 累计电量 |
| 累计电量 | 设备记录的累计值，不会在安装插件时从零开始 |

HA 已对电网和电池功率方向进行统一转换，与某些厂家后台的正负号可能相反。对比时应同时核对“充电／放电”“购电／上网”的含义和采样时间。

能流图会保留浅色的未活动连接线，仅有有效功率的路径显示流动。各路功率之间 30 W 以内的计量误差不会画成流向家庭的动画，此时光伏等来源的圈内数字可能与传感器相差几十瓦，传感器和统计仍是设备原始读数。低于 1 kW 的数值显示为 W；例如 45 W 不必读成 0.045 kW。家庭负载读数为负时，能流图和数字孪生按 0 W 显示、动画照常；超过 −30 W 时在图下（孪生在顶部）用一行文字注明实际读数，持续出现时请核对接线。原始传感器及统计保持设备读数，不自动修正成零。

### 4.2 数据多久更新

| 数据 | 正常读取间隔 |
|---|---|
| 光伏、电池、家庭负载、电网四项功率 | 约 10 秒 |
| SOC、运行状态、告警及按需启用的普通诊断数据 | 约 30 秒 |
| 累计电量、EMS 模式 | 约 60 秒 |
| 定时充放电计划常规读取 | 约 5 分钟 |

以上为正常轮询分档。通信重试、设备响应慢或其他操作可能延长更新时间。刷新浏览器不会强制设备立即上报新数据。

今日电量、近 7 天图表和左侧“能源”使用 HA 历史／统计数据，不是每次功率更新就立即重算。刚接入时，需要积累有效记录；没有历史数据时，图表可能为空。

“未知”“不可用”和“0”含义不同：未知表示尚无可用状态，不可用表示当前无法取得有效数据，0 则是有效读数。不要将不可用当作没有用电或没有故障。

## 5. 查看设备故障与告警

### 5.1 在哪里看

优先打开 **EnergyLIB → 总览 → 设备告警**。也可进入 **设置 → 设备与服务 → EnergyLIB → 设备**，点击“设备告警”查看状态和属性。

**“设备告警”同时包含故障、警告、提示及未识别异常。** 不再需要分别寻找“存在故障”“存在警告”或多个数量实体。

| 页面状态 | 含义 |
|---|---|
| 正常／运行正常，无告警 | 本轮告警来源完整，且没有激活项 |
| 有异常 | 存在已识别的故障、警告或提示，具体分类看明细 |
| 未识别异常 | 读到了激活项，但尚无确认的名称或分类 |
| 数据不完整 | 部分告警来源没有成功读取，不能据此判断全部正常 |
| 通信不可用 | 当前无法有效读取告警来源，应先检查连接 |

### 5.2 查看具体异常

出现异常时，卡片直接列出名称和分类。点击明细的首次检测时间可展开来源、功能码、代码及最近有效检测时间。

例如，协议已映射的 **“电池1欠压”** 激活后，会出现在当前清单中。该点在当前词典中属于**提示**，不会因为名称带“欠压”就自动归为故障。处理方式以厂家说明及现场设备状态为准。

点击 **最近记录** 查看历史，最多保存最近 100 次发生记录，包含首次检测、最近有效检测及检测到恢复的时间。这些是 HA 观察时间，不是逆变器内部故障发生时间。

通信中断时，上次有效的激活项会保留并标记过期；这不等于已经恢复。重新加载或重启后历史保留，启动时已有异常默认不会重复发送发生事件。

### 5.3 手机通知

插件不会直接发送手机通知。管理员可在 HA 中创建自动化，使用 `energylib_alarm_changed` 事件，按设备、分类、具体告警和发生／恢复条件选择通知目标。

可用分类为故障 `fault`、警告 `warning`、提示 `info` 和未知 `unknown`；变化类型为发生 `raised`、恢复 `cleared`。完整示例见 [故障与告警说明](ALARMS.md#persistence-and-events)。

## 6. 开放控制权限

控制默认关闭。仅需查看数据时保持关闭即可。

管理员进入 **设置 → 设备与服务 → EnergyLIB → 配置 → 控制权限**，打开 **允许控制** 并保存。设备必须提供所需控制点位，否则会提示无法开放控制。

从 0.8.25 起，新创建的 EMS 模式、备电 SOC、放电截止 SOC、电网充电及出口限制参数，在管理员打开“允许控制”后默认启用；开放权限本身不修改设备参数。既有被用户禁用的实体保留原设置，需在设备页 **已禁用实体** 中逐项恢复。远程充放电权限、功率／时长及按钮仍独立控制、默认禁用。若卡片未出现，可在 HA 加载完成后刷新页面。

请区分以下三个步骤：

| 操作 | 实际效果 |
|---|---|
| 打开“允许控制” | 开放该集成的控制入口，本身不开始充放电 |
| 打开“允许远程充放电” | 恢复关联操作实体并解锁手动任务，本身不开始任务 |
| 点击“开始充电／开始放电” | 按本次功率、时长提交任务 |

## 7. EMS 模式与常用参数

这些项目位于总览的 **运行控制** 区，也可在设备页操作。**修改 EMS 模式、SOC、电网充电和出口限制会下发到设备**，与仅保存手动充放电输入值不同。

### 7.1 EMS 模式

“EMS模式”是原“工作模式”的显示名称，位于控制区前部。选择后下发并回读确认。

| 模式 | 主要用途 |
|---|---|
| 自发自用 | 日常优先利用本地发电和储能 |
| 定时充放电 | 按设备中保存的时段表运行 |
| 灾备 | 按设备的备电策略运行 |
| 光伏优先充电 | 按设备策略优先利用光伏给电池充电 |
| 卖电优先 | 按设备的馈网优先策略运行 |
| 削峰填谷 | 按设备的削峰策略运行 |

具体优先级、可用模式及限制由设备固件决定；选择模式不等于同时配置了该模式的全部参数。只读状态中可能出现其他模式名称，控制下拉框仅提供当前支持的选项。

### 7.2 备电 SOC 与放电截止 SOC

| 参数 | 含义 |
|---|---|
| 备电 SOC | 为备电用途保留的目标电量阈值，具体作用取决于 EMS 模式和固件策略 |
| 放电截止 SOC | 允许放电的最低电量阈值；电池/BMS 保护还可能更早限制放电 |

放电截止 SOC 与备电 SOC 的组合应符合设备要求。例如备电 SOC 为 30%、放电截止 SOC 为 10%，表示两个不同用途的阈值，**不代表所有模式都一定会从 30% 放到 10%**。从0.8.36起，插件用已读取的当前值检查“放电截止SOC不能高于备电SOC”（两路电池分别检查），冲突时直接提示并不写入设备；这项检查不增加设备读取。输入范围为0～100%，设备拒绝或回读不符时也会报错。

这两项 SOC 的操作步长为 1%，与功率设置的 0.1 kW 步长不同。

存在两路电池时，相关参数会分别写入并确认；一台成功、另一台失败可能形成部分完成，应检查设备实际值。两个电池参数是否一致可在实体属性中查看。

基础设置在已完成初始化的健康连接上直接写入，再回读目标寄存器确认。EMS模式、电网充电、出口限制和单路SOC均为1次写入＋1次回读；双电池SOC分别执行，共4次请求。电池2诊断实体是否启用不改变双电池参数联动。首次初始化、重连、通信重试或失败恢复可能增加读取；不会通过提前显示成功来隐藏设备响应时间。远控任务进行中（包括从App发起、插件已读取到的会话）会阻止EMS模式切换。

### 7.3 允许电网充电

该开关表示是否允许设备使用电网给电池充电。**打开不等于立即开始充电**，仍取决于当前 EMS 模式、时段、SOC 和设备条件。

### 7.4 出口功率限制

“出口”指向电网馈电。需要配合使用两个项目：

1. 在 **出口功率限制** 中设置允许的最大上网功率，单位 kW。
2. 打开 **启用出口限制**，使设备应用该限值。

从 0.8.31 起，修改功率只写功率并回读确认，不自动打开限制开关；开关原来开启时继续开启，原来关闭时继续关闭。

限值上限取自设备能力。**0 kW 表示零出口目标，不表示关闭限制。** 需要取消限制时，使用“启用出口限制”开关；不要通过把限值设为 0 来取消。

出口功率限制的操作步长为 **0.1 kW**，设备页和总览统一显示一位小数。设置会等待设备回读确认；确认后先更新配置值，功率、电量等仍按正常周期刷新。设备通信重试或当前轮询尚未结束时，操作仍可能需要等待；不要连续拖动并把尚未确认的数值当成已生效。

### 7.5 电池充放电限值（高级）

从 0.8.37 起，设备支持时另外提供 **最高 SOC**（50～100%）、**最大充电电流**、**最大放电电流**（0～300 A）。这三项默认禁用，需要时在设备页 **已禁用实体** 中启用，启用后会出现在总览“运行控制”区。

- 修改会写入设备并回读确认；存在两路电池时两路同时写入，与 SOC 设置相同。
- 最高 SOC 不能低于备电 SOC，冲突时直接提示、不写入设备。
- 电流限值是设备允许的上限，实际充放电还受 BMS、SOC 和 EMS 模式限制。请按电池厂家给出的允许电流设置，不要超过电池规格。
- 设备读不到某项时，不会显示该项。

## 8. 电池强制充放电

这是一次性、有时长的手动操作；每天重复执行请使用下一节的定时充放电。当前远程充放电尚未经实机验证，实机操作应先完成现场确认。

### 8.1 开始一次任务

1. 确认管理员已开放 **允许控制**。
2. 打开 **总览 → 电池强制充放电**。
3. 开启 **允许远程充放电**，等待“正在启用操作实体”提示结束。HA 通常会在约 30 秒后重载并加载关联实体。
4. 选择 **充电** 或 **放电**。
5. 输入大于 0 的功率，单位 **kW**，不超过页面给出的设备上限。
6. 输入 **1～1440 的整数分钟**。初始功率为 0、时长为 5 分钟，功率为 0 时不能开始。
7. 点击 **开始充电** 或 **开始放电**，查看执行反馈。

例如，在设备允许的范围内填写功率 1 kW、时长 5 分钟并选择充电，点击开始后才提交本次 5 分钟充电任务。这里只是输入示例，不是对具体电池的推荐设置。

若提示当前处于定时充放电模式，应先明确退出该模式。卡片可用时提供 **退出定时模式** 操作；也可通过 EMS 模式选择器切换。开始按钮不会自动替用户切换模式。

### 8.2 怎么看是否执行

卡片会显示任务方向、本次设定、实际电池功率、预计结束时间及剩余时间。

**目标功率与实际功率应分开看。** 设备可能受 SOC、BMS、可用能量、电网充电权限等条件限制；提交成功不保证实际功率始终等于目标。

实机实测（盛弘 V001B031，2026-10-26）：
- **充电**：设定值就是电池充电功率。设定 2 kW 时电池以 2.0 kW 充电，光伏不够的部分从电网补。
- **放电**：设定值是逆变器的**总输出**（光伏 + 电池），不是电池单独的功率。设定 2 kW、光伏 0.74 kW 时，电池放电约 1.3 kW；光伏已超过设定值时，电池不放电。多出的电会送入电网。
- 因此放电时卡片里的"实际电池功率"通常小于设定值，差额就是当时的光伏功率。

“预计结束时间”只属于本次手动任务，等于开始时间加设置时长，不是预计充满时间，也不是 TOU 时段结束时间。没有任务时，卡片显示“暂无任务”；单独的时间戳实体可能显示“未知”。

### 8.3 修改、停止和重启

| 操作 | 结果 |
|---|---|
| 修改功率或时长 | 只保存本地输入，不写设备，不改变正在运行的任务 |
| 再次点击开始 | 使用该次点击时的方向、功率和时长更新任务 |
| 点击停止 | 请求退出本次远程任务并回读确认 |
| 关闭“允许远程充放电” | 先确认退出已有任务，成功后关闭权限；退出失败会保留权限并报错 |
| 关闭浏览器 | 不影响后端计时，到期由 HA 后端执行退出 |
| HA 重载或重启 | 保留输入值和远程权限，不自动恢复先前任务 |

出现 **执行结果未确认** 时，不能认为已开始或已停止。应核对设备实际状态和连接，必要时使用停止操作；不要连续点击开始。

心跳由插件内部维护，不需要用户设置。当前采用约 10 秒心跳、60 秒失联超时及自发自用退出策略，设备看门狗行为仍待实机验证。HA 崩溃或断电时，不能把页面上的计时当作设备已成功退出的证明。

## 9. 定时充放电（TOU）

### 9.1 设置并启用

1. 进入 **设置 → 设备与服务 → EnergyLIB → 配置 → 定时充放电**。没有此入口时，先检查控制权限及设备能力。
2. 使用 **添加时段**，选择充电或放电，填写开始、结束时间和功率。
3. 使用 **星期与时段外模式**，设置整张计划生效的星期及非时段内的模式。
4. 点击 **预览并保存**，检查整张计划。
5. 需要立即启用时，勾选 **保存后切换为定时充放电**；只保存不勾选时，不会自动把原来的非 TOU 模式切换为 TOU。
6. 保存后检查实际计划及 EMS 模式。若设备原本已处于 TOU，保存后的计划可能直接参与运行。

编辑过程暂存在草稿中，只有保存时才下发。关闭编辑窗口前没有保存的修改，不应当作已写入设备。

### 9.2 计划限制

- 充电、放电各最多 6 段；整张表共用一套星期设置。
- 时段不能重叠，不能跨零点；当前不支持直接设置 23:00 至次日 01:00。
- 不接受 `24:00`；不要用 `23:59` 代替午夜而期待相同效果。
- 功率不能超过设备允许范围。
- 生效起止日期当前只读。保存时，若设备原有有效期已经结束，会更新为当天至 2099 年 12 月 31 日；未过期的窗口和清空计划时的窗口保持原值。

### 9.3 查看状态、暂停和清空

可在设备页启用 **定时充放电计划** 诊断实体，在总览查看计划与状态。

| 状态 | 含义 |
|---|---|
| 充电时段／放电时段 | 当前日期、星期及时间匹配对应时段 |
| 不在时段内 | 当前不满足时段条件，也可能尚未到生效日期 |
| 有效期已过 | 当前日期超过计划的有效截止日期 |
| 未启用 | 当前 EMS 模式不是定时充放电 |
| 远程调度中 | 设备当前处于远程控制状态 |

暂时不用计划时，可明确将 EMS 模式切离“定时充放电”；这不会删除时段。需要删除时，可在编辑器逐项删除后保存，管理员也可使用清空计划动作。

保存是多次设备写入，可能部分完成。若提示失败或部分完成，应重新打开配置读取设备实际计划，再决定下一步，不能假定整张计划已保存或已自动回滚。

## 10. 配置 HA“能源”面板

左侧 **能源** 是 HA 原生统计页面，与 EnergyLIB 的实时总览不同。管理员可通过 **设置 → 仪表盘 → 能源** 进入配置；菜单名称可能随 HA 版本略有变化。

| 能源配置项目 | 选择的 EnergyLIB 累计传感器 |
|---|---|
| 电网购电 | 累计购电量 |
| 返回电网／上网 | 累计上网电量 |
| 太阳能发电 | 累计光伏发电量 |
| 电池充入 | 累计电池充电量 |
| 电池放出 | 累计电池放电量 |

选择单位为 **kWh** 的累计传感器，不要把 kW 功率填到累计电量位置。累计负载用电量可单独展示，不要重复加入同一能源平衡。

刚配置后请等待 HA 生成统计。累计值已经很大是设备历史累计的正常表现，今日用量看统计变化。不要为让图表归零而修改传感器值或清零逆变器电量。

若曾使用模拟设备，先由管理员备份，再确认需要清理的具体模拟统计；不要删除真实设备或其他家电的历史记录。

## 11. 启用诊断数据与查看版本

进入设备页的 **已禁用实体**，按需启用电网电压、频率、电池电压／电流／健康度、各路 PV、温度及电池 2 数据。接入 BMS 时，还可启用电池装机容量、剩余能量、单体最高／最低电压和温度，以及 BMS 允许的充／放电电流限值（0.8.37 起）。电池装机容量和剩余能量只在 BMS 上报了容量时才出现。

后来接入或拆除电池、BMS 时，插件约每 10 分钟重新识别一次设备能力，发现变化会自动重新加载，新增的实体随后出现在 **已禁用实体** 中；也可以在集成菜单中手动 **重新加载** 立即识别。启用后等待 HA 加载，再查看读数。

这些数据默认禁用，用于按需查看和排障；启用的测点会影响读取范围。设备必须识别出相应能力才会创建对应实体，例如 PV4 要求设备报告支持第 4 路，电池 2 也需要对应能力。没有实体时，不能仅靠手工启用来补出硬件能力。

BMS 未接入时，部分电池数据可能不可用，设备也可能返回 0；这不能证明电池实际为空或健康度为零，应结合接线及设备状态判断。

设备信息中的 **固件** 取自逆变器 ARM 版本，例如显示 **逆变器 V8.08**。旧版的 `8.8` 表示同一版本，显示格式优化不会升级设备固件。标注语言随 HA 系统语言设置，英文显示为 `Inverter V8.08`。

发现确认页的 **采集棒固件** 来自采集棒 mDNS 广播，两者不是同一个软件版本；逆变器固件字段不会被采集棒版本覆盖。

## 12. 常见问题

| 现象 | 建议检查 |
|---|---|
| 找不到自动发现卡片 | HA 与采集棒是否允许 mDNS；可改用实际 IP、端口、Unit ID 手动添加 |
| 已发现但添加失败 | 广播端口和设备地址是否正确，采集棒是否提供可读的 Modbus 服务 |
| 页面没有控制卡片 | “允许控制”是否开启，设备是否提供控制能力，相应实体是否已启用 |
| 远程权限打开，实体仍灰色 | 等待关联实体加载；若持续未恢复，检查集成加载状态和错误日志 |
| 开始按钮不能点击 | 功率是否大于 0 且未超上限，时长是否为 1～1440 的整数，是否仍处于 TOU，操作实体是否就绪 |
| 提示开始失败或执行未确认 | 检查设备实际状态及通信；不要将失败提示当成已经成功执行 |
| 有目标功率，但实际功率不同 | 核对电池 SOC、BMS、当前能量来源、电网充电权限和设备限制 |
| 告警显示“数据不完整” | 展开查看过期来源；恢复通信后再判断，不能按无告警处理 |
| 今日电量或近 7 天图为空 | 检查 Recorder、累计传感器和统计是否已有有效数据，等待统计生成 |
| 与厂家后台读数不同 | 对齐采样时间、kW/kWh 单位及功率方向；确认比较的是同一台设备、同一累计项目 |
| 升级后页面仍是旧样式 | 确认 HA 已完成重启，再强制刷新浏览器；电脑常用 Ctrl+Shift+R |
| 页面报 404 | 检查访问的仪表盘是否仍存在，避免使用已删除的旧地址；返回 HA 首页再打开当前 EnergyLIB 页面 |
| 数字孪生首次加载慢 | 等待静态资源加载；主要场景先显示，汽车随后加载；检查网络和浏览器状态 |

需要反馈问题时，进入 **设置 → 设备与服务 → EnergyLIB** 的条目菜单或设备页，选择 **下载诊断信息**。同时记录集成版本、HA 版本、问题发生时间、操作步骤和页面提示，便于复现。

诊断导出采用脱敏字段，但自行提供截图、日志时仍应检查是否包含完整 SN、地址、账号或其他隐私信息。

## 13. 自动化使用者参考

日常用户可直接使用总览。需要自动化时，在 HA 的 **开发者工具 → 动作** 中选择 EnergyLIB，设备使用实际的设备选择器，不要照抄别人的实体 ID。

| 动作 | 用途和单位 |
|---|---|
| `energylib.set_remote_access` | 打开／关闭远程操作权限；打开不会开始任务 |
| `energylib.set_remote_parameters` | 保存正数功率及整数分钟，不写设备，不开始任务 |
| `energylib.set_battery_power` | 提交远程任务；功率 kW，负数充电、正数放电；`duration` 为 1～86400 秒 |
| `energylib.stop_battery_power` | 停止远程任务并回读 |
| `energylib.set_tou_schedule` | 替换整张 TOU 计划，不是追加单个时段 |
| `energylib.clear_tou_schedule` | 清空时段，保留设备生效日期，不隐式切换 EMS 模式 |

所有入口仍受控制权限及能力校验约束。旧功率动作兼容 0 kW；总览的新开始入口要求大于 0。旧版立即执行 5 分钟的滑块和开关已退役，相关自动化应改用公开动作。

更多信息：[远程充放电](REMOTE_DISPATCH.md)、[故障与告警](ALARMS.md)、[安装与维护](OPERATIONS.md)、[测试范围](TESTING.md)。
