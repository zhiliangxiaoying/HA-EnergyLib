# 采集棒 mDNS 设备发现协议

**版本：V1.0 · 日期：2026-10-20**

用于电脑或手机在同一局域网中自动发现采集棒，取得设备信息和连接地址。本规范由我方统一定义，设备端按以下要求实现。

## 1 发现方式

- 采用标准 mDNS + DNS-SD，无需互联网。
- 服务类型固定为 `_energylib._tcp`。
- 发现使用 UDP 5353，IPv4 组播地址为 `224.0.0.251`。
- 设备取得有效 IP 且业务服务就绪后，10 秒内可被发现。

## 2 发现信息

| 信息 | 要求 |
| --- | --- |
| 设备显示名称 | 默认使用 `EnergyLIB-<SN>`，保留 SN 原始大小写，例如 `EnergyLIB-ELIB260002` |
| 实例完整名称 | 由设备名称、服务类型和域组成，即 `<设备名称>._energylib._tcp.local.` |
| 主机名 | 默认使用 `energylib-<SN小写>.local.`，例如 `energylib-elib260002.local.`，通过 SRV 指向该主机名 |
| IP 地址 | 通过 A 记录将主机名解析到设备当前有效 IPv4 地址 |
| 业务端口 | 通过 SRV 返回实际监听的 TCP 端口，客户端不固定端口值 |

设备提供标准 PTR、SRV、TXT、A 记录，并响应 `_services._dns-sd._udp.local.` 服务类型枚举，便于通用工具扫描。

设备显示名称与主机名是两个不同对象。主机名的 `energylib-<SN小写>` 标签仅使用 ASCII 字母、数字和连字符，最多 63 字节；SN 中其他字符替换为连字符，过长时截短该标签。名称冲突时自动追加序号，并保持标签长度合规；TXT 中的 `sn` 始终保留完整原始值。示例末尾的点表示完整域名，工具显示时可省略。

## 3 TXT 字段

以下六个字段均为必填，用于描述采集棒身份、版本和本地业务服务。

| 字段 | 含义 | 要求 |
| --- | --- | --- |
| `sn` | 采集棒序列号 | 唯一、与标签一致，重启及恢复出厂后不变 |
| `model` | 采集棒型号 | 返回正式型号 |
| `fw` | 采集棒固件版本 | 返回当前实际运行版本，升级成功后更新 |
| `transport` | 本地业务通信方式 | 本版为 `modbus_tcp`，表示 SRV 端口提供 Modbus TCP 服务 |
| `api_ver` | 本地业务协议版本 | 本版为 `1`，与固件版本分别管理；业务协议发生不兼容变更时递增 |
| `auth` | 本地业务认证方式 | 无需应用层认证时为 `none`；需要认证时使用对应业务协议定义的标识，且与实际行为一致 |

设备唯一标识统一使用 `sn`，不再单独定义 `id`。`sn`、`model`、`fw` 均描述采集棒，不使用逆变器的对应信息替代。`api_ver` 描述本地业务接口，不是 mDNS 或逆变器串口协议版本。

各字段分别编码为 `key=value`，使用标准 DNS-SD TXT 格式，每个键只出现一次，不合并为 JSON。客户端忽略未知字段。

示例值仅说明格式：

```text
sn=ELIB2026000001
model=LOGGER-01
fw=1.0.0
transport=modbus_tcp
api_ver=1
auth=none
```

IP 和业务端口从标准地址记录与 SRV 中获取，不在 TXT 中重复填写。

`auth` 只声明认证方式，不携带密码或令牌。客户端遇到未知认证方式时，不得按免认证处理。

## 4 运行要求

1. 联网、重启、重连或 IP 变化后，自动发布当前有效信息。
2. 多台设备同时在线时，以 `sn` 区分身份，不以名称或 IP 作为唯一标识。
3. 正常停止服务时发送标准注销通知；突然断电或断网时，客户端结合缓存和实际连接结果判断在线状态。
4. 发现后，通过返回的 IP 和业务端口，按本地业务协议连接设备。mDNS 仅负责发现，不定义业务读写报文。
5. 在线状态、首次发现时间和最后发现时间由客户端判断及记录，设备不发布对应 TXT 字段；列表中存在缓存记录不代表设备仍可连接。

## 5 验收

- 同一允许组播的局域网内，业务就绪后 10 秒内可发现，六个 TXT 字段完整且正确。
- 返回的 IP 和端口可以实际建立业务连接。
- `transport`、`api_ver` 和 `auth` 与实际业务服务一致，Modbus TCP 服务可完成一次有效请求与响应。
- 至少三台同时在线时身份不混淆；重连或 IP 变化后可重新发现，SN 保持不变。

实现依据：[RFC 6762](https://www.rfc-editor.org/rfc/rfc6762.html)、[RFC 6763](https://www.rfc-editor.org/rfc/rfc6763.html)。服务类型、TXT 字段和 10 秒指标为本项目要求。
