## 阶段 1：HA 发现与只读接入

- [ ] 建立完整 manifest 和原生配置流程。
- [ ] 实现 Zeroconf 发现、去重、地址更新及手动配置入口。
- [ ] 建立协议通信层、型号适配器和统一数据协调器。
- [ ] 读取设备身份、运行状态、系统功率、电池 SOC 和基础告警。
- [ ] 提供中文和英文文本、脱敏诊断、必要的自动化测试。
- [ ] 在指定型号/固件实机上完成只读验证。

## 阶段 2：能源统计与安装体验

- [ ] 校验累计发电/购电/上网/电池充放电电量。
- [ ] 验证长期统计、计数器复位、时区与日界线。
- [ ] 编写能源面板配置及排障指南。
- [ ] 建立代码检查、测试和 HACS 验证工作流。
- [ ] 验证后声明最低 HA 版本，提供首个可安装版本。

## 阶段 3：可选控制

- [ ] 建立逐型号控制能力及授权范围。
- [ ] 实现参数校验、请求协调、执行回读和错误反馈。
- [ ] 在明确授权的监督窗口中逐项实机验证。
- [ ] 文档说明本机模式/时间计划/外部 HEMS 的优先级和冲突处理。
- [ ] 提供基础与高级控制的可选显示方式。

## 阶段 4：扩展型号和能源联动

- [ ] 按型号及固件逐步扩展 LIB 设备支持。
- [ ] 验证多机、并机、外接电表和电池拓扑。
- [ ] 提供 HEMS/EMHASS 联动示例，仅使用已验证的数据和控制接口。
- [ ] 完成版本升级、回滚、发布记录和问题反馈流程。
