# EnergyLIB integration component

Home Assistant integration (`energylib`) for a single inverter using the V001B031 Modbus
protocol over Modbus TCP, with `_energylib._tcp.local.` discovery, opt-in controls and a
time-of-use editor. Development preview; controls are not hardware-verified.

See the repository [README](../../README.md) for installation, configuration and limits.
The vendor protocol document is not distributed with this component.
