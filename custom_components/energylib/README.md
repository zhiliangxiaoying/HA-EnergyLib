# EnergyLIB integration component

Home Assistant integration (`energylib`) for a single inverter using the EnergyLIB Modbus
protocol over Modbus TCP, with `_energylib._tcp.local.` discovery, controls (on for new
inverters, can be turned off) and a time-of-use editor. Development preview; controls were
tested on one three-phase 12 kW inverter.

See the repository [README](../../README.md) for installation, configuration and limits.
The protocol document is not distributed with this component.
