# Vendor protocol documents (local only)

This directory is reserved for vendor protocol documents (inverter, BMS, meter,
communication dongle) used during development. Everything here except this README and
`.gitignore` is excluded from git: vendor documents are **not** distributed with the
integration.

Project design documents live in [`docs/`](../docs/).

本目录用于在本地存放厂家协议资料（逆变器、BMS、电表、通讯棒等）。除本说明和 `.gitignore` 外，
其余文件都不会提交到 git，厂家协议文件**不随集成分发**。项目设计文档见 [`docs/`](../docs/)。
